📜 Pandas Ki History (Yeh Kaise Shuru Hui?)
Pandas ko saal 2008 mein ek software developer aur statistician Wes McKinney ne banana shuru kiya tha.

Wajah kya thi? Wes McKinney us waqt ek investment firm (AQR Capital Management) mein kaam karte the. Wahan unhein financial data (jaise stock prices aur tables) par research karni hoti thi.

Problem: Us daur mein Python mein tables aur data par kaam karna bohot mushkil tha. Excel slow ho jata tha aur baaki programming languages bohot complex thi.

Solution: Wes ne khud se ek aisi library likhna shuru ki jo fast bhi ho aur Excel ki tarah rows/columns ko aasaani se handle kar sake. 2009 ke aakhir mein isko Open Source (sabke liye muft) kar diya gaya, aur aaj yeh duniya ki sabse mashhoor data library ban chuki hai.

📛 Iska Naam "Pandas" Kyun Hai?
Kayi log samajhte hain ke iska naam us pyaare se bhaloo (Pandas animal) par rakha gaya hai, lekin aisa nahi hai!

Yeh actually ek short-form hai:

PANel DAta (Panel Data)

Aur saath mein Structures.

Econometrics aur statistics mein jab hum kisi data ko tables ke format mein analyze karte hain (jismein rows aur columns hon), to use Panel Data kaha jata hai. Wahin se yeh naam nikal kar aaya Pandas.

🏗️ Pandas Itni Powerful Aur Fast Kyun Hai?

Python upar se sirf ek interface ka kaam karti hai, lekin background mein saari tez-tarreen calculation C language ki speed par hoti hai. Isiliye yeh lakhon rows ka data milliseconds mein filter kar deti hai.
